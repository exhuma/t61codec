# Security policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please report vulnerabilities privately, either through GitHub's
["Report a vulnerability"](https://github.com/exhuma/t61codec/security/advisories/new)
button (private vulnerability reporting) or by e-mail to michel@albert.lu.
Please do not open a public issue.

Responses are best effort; this is a maintenance-mode project.
