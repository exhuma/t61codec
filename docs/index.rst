Python Character Mapping Codec for the `ITU T.61 <https://en.wikipedia.org/wiki/ITU_T.61>`_ character set.

T.61 is an 8-bit character encoding standard defined by the International Telecommunication Union (ITU).
It is historically used in X.500 directory services and related protocols such as LDAP.
